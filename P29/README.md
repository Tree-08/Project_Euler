# Problem 29 — Distinct Powers

[Problem link](https://projecteuler.net/problem=29)

How many distinct terms are in the sequence generated by `aᵇ` for `2 ≤ a ≤ 100` and `2 ≤ b ≤ 100`?

## Approach

Compute every `aᵇ` exactly and put it in a set, then take the set's size.

- Python integers have arbitrary precision, so even `100¹⁰⁰` is exact and there are no floating-point collisions to worry about.
- `binpow` is a hand-written exponentiation by squaring (`aᵇ = (a^⌊b/2⌋)² · a^(b mod 2)`). It is equivalent to Python's built-in `a ** b`.
- Duplicates arise when two bases are powers of the same root, e.g. `2⁴ = 4² = 16`, and the set removes them automatically.

There are 99 × 99 = 9801 pairs, and 9183 of them are distinct.

## Complexity

9801 exponentiations of O(log b) big-integer multiplications each — instant.

## Run

```
python P29.py
```

## Answer

`9183`
